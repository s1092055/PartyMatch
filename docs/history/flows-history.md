# Flows 演變記錄

這裡簡要記錄各功能流程曾經歷過的設計變化，主文件只保留現況。

- UI 細節多次微調：說明泡泡展開方向、分頁整併回單一概覽畫面、卡片文案與統計格用詞多次調整以更貼近實際狀態語意
- 幾個入口位置搬遷：填寫帳號、信用分數查看等功能從側邊欄改成頁面內動態按鈕/區塊
- 「我的群組」從單一頁面依身分切換，拆回兩個獨立頁面（成員視角／團主視角），移除切換身份按鈕，改成兩個獨立導覽入口
- 修過幾個「狀態轉換」與「退款/通知」耦合在一起導致邊界情況出錯的 bug（例如特定情境下狀態被誤判成不用處理而卡住）
- 清理過幾次文件與程式碼裡的「死內容」：從未真正實作過的規劃殘留狀態、資料庫從未使用過的舊欄位、程式碼裡不會命中的判斷分支，以及過期沒更新的技術文件清單
- 篩選條件的儲存方式從瀏覽器 session 儲存改成純頁面內狀態，離開頁面即清空，減少不必要的同步邏輯
- 團主提供帳密的服務，鎖定群組時的輸入方式從自由文字改成結構化表單，並在成員查看時加上浮水印
- 移除過未使用的第三方套件依賴（評估過但最終沒有採用）
