# 演變記錄

`docs/` 底下其他文件只描述目前的狀態與規則。這裡保存了曾經寫在正文裡、但屬於「以前怎麼做、後來為什麼改成現在這樣」的設計演變敘述，避免正文夾雜過程細節。

- [Flows 演變記錄](flows-history.md) — 使用者流程相關文件（分頁改版、入口位置搬遷、文案演變等）
- [Architecture / Product 演變記錄](architecture-product-history.md) — 架構與產品文件相關的設計決策演變
- [Testing 演變記錄](testing-history.md) — 測試案例文件裡曾經存在、與 bug-log.md 無關的 UI/流程改版敘述
- [Portfolio 演變記錄](portfolio-history.md) — 作品集文件裡的技術方案遷移過程

已修復 bug 的完整歷史（發現方式、重現步驟、修正方式）另外記錄在 [Bug Log](../testing/bug-log.md)，不重複收錄在這裡。
