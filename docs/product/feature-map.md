# 功能地圖

核心流程：**探索群組**（可搭配條件搜尋精準篩選）→ **建立群組**（4 步驟表單，含即時預覽）→ **申請與審核**（送出即代管扣款，審核通過建立成員、拒絕退款）→ **PM 幣代管與撥款**（服務啟用時撥給團主）→ **續訂與申訴**（團主手動開啟續訂；申訴由管理員裁定）。

其他功能：

- **我的訂閱／群組管理**：成員與團主各自視角管理群組、追蹤狀態、查看歷史紀錄
- **管理員後台**：獨立路由，平台概覽數據、系統訊息（廣播/單發）、申訴裁定
- **聊天室與通知**：群組聊天室、私人 DM、系統通知，皆可附加圖片；共用帳密群組另有獨立的「帳號資訊」留言區
- 收藏群組、帳號設定（個人資料、PM 幣、隱私偏好）、雙向互評（團主與成員互相評價，連動信用分數）

各功能對應的前端元件、Store、API 與後端 Route 詳見程式碼內對應目錄結構。
