# 頁面地圖

主要路由（除 `/`、`/create-group` 外皆掛在共用 `AppLayout` 之下，共用 sidebar／底部 Dock 導覽）：

| 路由 | 用途 |
|------|------|
| `/` | 行銷首頁，8 個整頁吸附區塊：Hero「探索群組」CTA、為什麼選擇 PartyMatch、適合每一種共享生活、精選群組輪播、自己開團輕鬆管理、我想成為（團主/成員身份流程）、CTA、FAQ |
| `/login`／`/register`／`/forgot-password` | 登入、註冊、忘記密碼 |
| `/explore` | 探索所有群組：分類篩選、關鍵字搜尋、排序 |
| `/groups/:groupId` | 導向探索頁並開啟指定群組詳情，供分享連結 |
| `/disclaimer`／`/terms`／`/privacy` | 法律文件頁 |
| `/my-subscriptions` | 「我的訂閱」，成員視角管理已加入群組 |
| `/manage-groups` | 「群組管理」，團主視角管理自己建立的群組 |
| `/favorites` | 已收藏群組列表 |
| `/create-group` | 4 步驟建立群組表單 |
| `/admin` | 管理員後台（獨立 layout，需管理員權限）：平台概覽數據、系統訊息、申訴裁定 |

此外，快速搜尋、群組詳情、群組管理、聊天室、儲值、通知、個人資料、帳號設定等功能以全域 Modal／面板形式疊加在既有頁面上（事件驅動觸發或側邊欄使用者選單觸發），沒有獨立網址；帳號中心已不再是獨立頁面，`/quick-match`、`/account` 兩個舊路由都僅保留相容重導向。
