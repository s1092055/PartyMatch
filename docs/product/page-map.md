# 頁面地圖

主要路由（除 `/admin` 系列外皆掛在共用 `AppLayout` 之下，共用側邊欄／導覽選單）：

| 路由 | 用途 |
|------|------|
| `/` | 行銷首頁：Hero、PartyMatch 是什麼、適合每一種共享生活、為什麼選擇 PartyMatch、精選群組輪播、常見問題、CTA，依內容自然高度呈現、非整頁吸附 |
| `/login`／`/register`／`/forgot-password` | 登入、註冊、忘記密碼 |
| `/explore` | 探索所有群組：分類篩選、依建立時間排序 |
| `/groups/:groupId` | 導向探索頁並開啟指定群組詳情，供分享連結 |
| `/disclaimer`／`/terms`／`/privacy` | 法律文件頁 |
| `/my-subscriptions` | 「我的訂閱」，成員視角管理已加入群組 |
| `/manage-groups` | 「群組管理」，團主視角管理自己建立的群組 |
| `/favorites` | 已收藏群組列表 |
| `/admin/login` | 管理員專用登入頁，與一般使用者登入分開 |
| `/admin` | 管理員後台（獨立 layout，需管理員權限）：平台概覽、系統訊息、帳號管理、平台回報、申訴裁定 |

此外，建立群組、群組詳情、群組管理、聊天室、儲值、通知、個人資料、帳號設定、條件搜尋等功能以全域 Modal／面板形式疊加在既有頁面上（事件驅動觸發或側邊欄使用者選單觸發），沒有獨立網址；`/create-group`、`/account`、`/quick-match` 為舊路由相容重導向，導回對應頁面並自動開啟相對應的 Modal，不是獨立頁面。
