# 各服務帳號共享機制調查

平台目錄中的 28 種訂閱服務，實際的多人共享機制並不統一，因此「填寫服務帳號資訊」表單依服務類型動態顯示不同欄位，而非單一固定格式。調查後歸納出幾種典型模式：

- **家庭群組型**（Apple Family Sharing、Google 家庭群組）：綁定到整個家庭群組而非單一訂閱，且成員異動有官方頻率限制，是較「重」的一種綁定
- **官方獨立邀請制**：多數服務只需 email，團主用官方邀請功能寄出邀請信即可，各自帳號互不影響
- **email + 額外驗證型**：少數服務（如 KKBOX）除了 email 還需要額外資訊（例如居住地址）才能完成驗證
- **邀請碼型**：少數服務（如 friDay影音）的綁定方向相反，由成員自己產生邀請碼交給團主
- **無官方邀請機制、僅能共用帳密型**：部分服務（如 Netflix、Disney+ 等）官方完全沒有多人邀請功能，只能共用登入帳密，風險最高。這類服務改由團主鎖定群組時透過結構化表單填寫帳密資訊，成員端直接查看（加浮水印防外流），流程與文案跟其他「填寫服務帳號」的情境明確區隔開來

這套分類已落地到服務目錄資料與對應的表單元件中，依各服務的共享機制自動顯示正確的欄位與提醒文案。
