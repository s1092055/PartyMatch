# 產品總覽

## 產品是什麼

PartyMatch 是共享訂閱媒合平台，讓使用者探索或建立 Netflix、Spotify、YouTube Premium、Disney+ 等訂閱服務的合購群組，找夥伴、審核、代管付款、服務啟用、續訂到申訴，整個流程都在平台內完成。

## 解決的問題

共享訂閱的媒合目前多半靠 Facebook 社團、PTT、Discord 私訊或 Google 表單處理：團主與成員互不認識、難以判斷信任度，付款紀錄散落在截圖跟對話裡事後難對帳，也沒有審核機制、詐騙風險高。PartyMatch 把媒合、審核、代管撥款、服務帳號確認做成平台內建流程，用 PM 幣（平台內部代管餘額）取代私下轉帳，金流與狀態雙方都查得到。

## 三種角色

- **成員**：探索/搜尋群組、申請加入、填寫服務帳號、追蹤訂閱、儲值、申訴、留評價
- **團主**：建立群組、審核申請、鎖定群組、啟用服務、開始續訂或結束群組
- **管理員**：獨立後台，看平台數據、發公告、裁定申訴

一個使用者可以同時是某群組的團主，也是另一群組的成員。

## 核心流程

探索群組 → 送出申請（PM 幣進代管）→ 團主審核 → 額滿後鎖定並開聊天室 → 成員填寫服務帳號資訊 → 團主啟用服務、代管撥款 → 續訂或結束，有爭議可申訴由管理員裁定。

## 功能亮點

群組走完整的**狀態機**：招募 → 額滿 → 填寫資訊 → 啟用 → 服務中 → 續訂／結束，每個階段能做什麼由狀態決定，不會跳步驟。錢的部分用 **PM 幣代管**，申請當下就先扣款，等啟用服務、成員確認後才撥給團主；退出、移除、解散、申訴都有對應退款規則。

其他重點：

- **信用分數**依行為即時增減（0–100），可作群組申請門檻；逾期未填帳號資訊會被自動移出並扣分、進入重新申請冷卻期
- 28 種訂閱服務、6 種共享機制，依服務動態顯示要填寫的帳號資訊欄位
- **申訴機制**：糾紛先自行協調，協調不成由管理員裁定
- 群組聊天室、私訊、系統通知整合成單一訊息中心
- 敏感資料（共用帳密、成員服務帳號）依角色動態遮罩並加密儲存，附件皆私有化

## 目前狀態

MVP 階段，核心流程皆已實作。PM 幣代管與付款為平台內模擬邏輯，尚未接上真實金流；訊息採 polling 而非即時推播。
