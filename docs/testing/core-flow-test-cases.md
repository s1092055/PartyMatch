# 核心主線測試案例

涵蓋交易主線：建立群組 → 申請加入（代管扣款）→ 團主審核 → 額滿鎖定 → 填服務資訊 → 團主啟用（48h 確認期）→ 成員確認（撥款）。

## 測試分類

- 團主建立群組、成員申請加入（餘額充足/不足兩種路徑）、取消申請退款
- 團主審核（接受/拒絕）、併發重複接受的防護
- 額滿自動鎖定、名額已滿後拒絕新申請
- 鎖定後名單鎖死、成員依服務類型填寫帳號資訊
- 啟用服務進入確認期、成員主動確認立即撥款、逾期未操作自動撥款
- 年繳計費路徑（席位費用 = 月費 × 12）
- App 啟動失敗與樂觀更新失敗的錯誤處理（回滾 + 提示）

測試帳號規劃僅供開發測試使用，不對外公開。
