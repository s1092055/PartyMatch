# 手動測試計畫

本文件用於功能驗證，確保 PartyMatch 主要功能（媒合 → 申請 → 審核 → 付款代管與確認 → 啟用服務 → 續訂/結束）可正常運作。

## 測試哲學

- 以核心交易流程（P0）為優先，其次是角色細節與邊界情況（P1/P2）
- 每個角色（團主/成員）獨立驗證，再驗證跨角色互動（訊息、通知）
- 手動測試發現的問題會回饋修正並記錄，避免回歸

## 涵蓋範圍（測試分類）

- 核心主線：建立群組 → 申請 → 審核 → 鎖定 → 填寫服務資訊 → 啟用 → 確認
- 團主視角：審核、成員管理、續訂、結束、收款管理、申訴裁定
- 成員視角：申請、確認服務、申訴、退出、評價
- 訊息與通知：群組聊天室、私訊、系統公告、未讀與已讀
- 探索與帳號：篩選搜尋、快速配對、收藏、付款方式、隱私設定
- RWD：手機／平板／桌機三種寬度下的版面切換

測試帳號規劃見 [`test-accounts.md`](./test-accounts.md)。
