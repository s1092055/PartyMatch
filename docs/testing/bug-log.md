# Bug Log

使用下面的格式記錄手動測試時發現的問題。優先記錄 P0/P1（會影響主線交易流程或資料正確性的問題），P2 視情況記錄。

## 範本

```md
### BUG-001：{標題}
- **功能**：{屬於哪個功能，可連結對應的 flows/ 文件}
- **嚴重度**：P0 / P1 / P2
- **測試帳號**：{見 test-accounts.md}
- **操作步驟**：
  1. ...
  2. ...
- **預期結果**：...
- **實際結果**：...
- **推測原因**：{可附檔案/行號}
- **修正狀態**：未修 / 已修（附 commit）
```
