# 手動測試計畫

本文件用於功能驗證，確保 PartyMatch 主要功能（媒合 → 申請 → 審核 → 付款代管與確認 → 啟用服務 → 續訂/結束）可正常運作。核心交易流程（P0）優先驗證，角色細節與邊界情況（P1/P2）其次；先各自驗證團主/成員角色，再驗證跨角色互動（訊息、通知）。發現的問題回饋修正並記錄於 [Bug 紀錄](bug-archive.md)，避免回歸。

## 涵蓋範圍（測試分類）

- 核心主線：建立群組 → 申請 → 審核 → 鎖定 → 填寫服務資訊 → 啟用 → 確認
- 團主視角：審核、成員管理、續訂、結束、收款管理、申訴裁定
- 成員視角：申請、確認服務、申訴、退出、評價
- 訊息與通知：群組聊天室、私訊、系統公告、未讀與已讀
- 探索與帳號：分類篩選、條件搜尋、收藏、隱私設定
- 管理員後台：平台概覽、系統訊息、申訴裁定
- RWD：手機／平板／桌機三種寬度下的版面切換

測試帳號規劃僅供開發測試使用，不對外公開。
