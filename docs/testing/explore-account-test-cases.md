# 探索頁／快速搜尋／收藏／帳號中心測試案例

涵蓋：探索頁篩選與排序、快速搜尋（`QuickMatchModal`）三步驟、收藏、帳號中心（隱私設定、刪除帳號）。

## 測試分類

- 探索頁：分類/服務篩選連動、關鍵字搜尋、價格篩選（預設區間與自訂金額）、排序切換、空狀態
- 快速搜尋：免登入使用、服務/方案多選、費用區間滑桿、信用分數門檻、搜尋結果與名次徽章、未登入導向登入頁
- 收藏：加入/移除（toggle 冪等）、收藏清單頁
- 帳號中心：刪除帳號（軟停用，需密碼驗證）
- 未登入訪客瀏覽帳號中心（各分頁鎖定提示）
- 隱私設定「顯示自己的大頭照」、目前狀態（線上狀態點）的顯示與切換

測試帳號見 [`test-accounts.md`](./test-accounts.md)。RWD 相關細節另見 [`rwd-test-cases.md`](./rwd-test-cases.md)。
