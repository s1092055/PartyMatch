# 探索頁／條件搜尋／收藏／帳號中心測試案例

涵蓋：探索頁分類篩選、條件搜尋三步驟、收藏、帳號中心（隱私設定、刪除帳號）。

## 測試分類

- 探索頁：分類篩選連動、依上架時間新到舊排序、空狀態
- 條件搜尋：從探索頁按鈕開啟、免登入使用、服務/方案多選、關鍵字、費用區間滑桿、信用分數門檻、搜尋結果與名次徽章、未登入導向登入頁
- 收藏：加入/移除（toggle 冪等）、收藏清單頁
- 帳號中心（個人資料／偏好設定 Modal）：刪除帳號（軟停用，需密碼驗證）、隱私設定「顯示自己的大頭照」、目前狀態（線上狀態點，自動偵測視窗焦點）的顯示
- 未登入訪客：使用者選單改顯示直接連到 `/login` 的連結，不出現帳號中心入口

測試帳號規劃僅供開發測試使用，不對外公開。RWD 相關細節另見 [`rwd-test-cases.md`](./rwd-test-cases.md)。
