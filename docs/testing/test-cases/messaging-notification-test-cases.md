# 訊息與通知測試案例

涵蓋群組聊天室、私人 DM、系統通知、通知中心的收發與導向邏輯。

## 測試分類

- 群組聊天室基本收發（REST polling，非即時 WebSocket），含圖片附件
- 私人 DM 延遲曝光（雙方在第一則訊息送出前都看不到空聊天室）
- 系統通知聊天室唯讀、系統公告防偽造（僅後端可標記為公開）
- 未讀數計算與已讀標記
- 通知點擊導向對應畫面（依當下最新狀態判斷，不依賴過期本地快取）
- 未登入使用者的通知面板（僅顯示公開系統公告）
- 頭像狀態點（線上/忙碌/離線）在訊息列表與成員面板的顯示與同步
- 退款/撥款相關通知連動即時刷新 PM 幣餘額

測試帳號規劃僅供開發測試使用，不對外公開。相關流程細節見 [訊息流程](../../flows/messages-flow.md)、[通知流程](../../flows/notification-flow.md)。
