# RWD 測試案例

「有沒有 hover 能力」跟「螢幕寬度」是兩個獨立維度：iPad 橫向雖然寬，但沒有滑鼠 hover，容易被單看寬度的判斷誤認成桌機。靠 hover 展開/顯示內容的元件（側邊欄、捲動提示）要同時檢查兩個條件；純內容排版（grid 欄數、篩選列橫排/直排）看寬度即可。

## 測試分類

- 主導覽：手機/iPad 共用左側滑出的 Drawer，僅有滑鼠 hover 能力的真桌機顯示可展開側邊欄
- 我的訂閱／群組管理頁面版面（單欄 grid 卡片列表，隨寬度自動調整欄數）
- 群組詳情 Modal 側邊欄（桌機並排、手機橫向捲動）
- 探索頁篩選列（分類 pill、搜尋框、篩選 combobox 的排版切換）
- 建立群組／快速搜尋全螢幕步驟流程頁的版面與捲動行為
- 卡片列表 grid 欄數（手機 1 欄 → 平板 2 欄 → 桌機 3 欄）
- 快速搜尋結果卡片 hover 放大與名次徽章顯示

實測建議至少涵蓋手機 390px、iPad 直向 768px 與橫向 1024px、桌機 1440px 四種寬度。
