# 測試帳號清單

`server/prisma/seedDemo.js` 建立 10 個 demo 帳號（3 位團主、6 位一般成員、1 位管理員），涵蓋 22 個處於不同狀態（招募中、已額滿、確認期、申訴中、已完成、已解散……）的群組，供手動測試各種情境使用。一般帳號密碼皆為 `Demo1234`。

[線上 Demo](https://partymatch.ykk910309.workers.dev) 的正式資料庫已灌入這批帳號，可直接登入體驗。

## 帳號規劃概要

- **團主帳號**（3 個）：涵蓋「同一人身兼多個群組團主、又是別的群組一般成員」的身分交錯情境
- **一般成員帳號**（6 個）：PM幣餘額與信用分數刻意拉開高低落差，用來測試餘額不足擋下申請、信用分數篩選等邊界情況
- **管理員帳號**（1 個）：獨立於一般角色之外，唯一能操作申訴裁定與管理員後台的帳號

seed 腳本透過真實 REST API（而非直接寫資料庫）依序驅動每個情境，確保資料狀態、代管金額等都是正式程式碼實際跑過一次的結果。

## 管理員帳號

**密碼刻意不寫在這份文件裡**：管理員後台能對全平台使用者廣播/單發系統訊息，不像其他 demo 帳號只影響自己名下的資料，所以不適合跟其他測試帳密一樣公開在 repo 裡讓任何人登入。本機開發環境下管理員密碼與一般帳號相同，正式環境則使用只有專案擁有者知道的獨立密碼。
