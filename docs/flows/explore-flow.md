# 探索群組

## 使用者目標
瀏覽目前開放招募的群組，透過分類、服務、價格上限、關鍵字搜尋與排序，找到符合需求的合購群組。

## 流程
1. App 啟動時先在背景快取一份群組列表
2. 使用者進入探索頁，篩選條件預設為「不限」，並自動排除自己開的團
3. 調整分類、服務、價格上限、排序或輸入關鍵字，全部是前端立即套用，不會重新打 API
4. 依條件過濾出招募中且有名額的群組（已加入的群組即使額滿也仍可見），套用排序後顯示
5. 卡片上標記使用者自己「已申請」或「已加入」的狀態
6. 點擊卡片開啟群組詳情，後續申請流程見 [申請加入流程](./apply-join-flow.md)

## 產品決策
- **篩選條件不記憶、不進網址**：離開或重新整理頁面就回到預設值，保持每次進來都是乾淨的起點
- **篩選與排序全部在前端運算**：對已快取好的資料做過濾，不會為了每次調整篩選就重新查詢後端，體感更快
- **關鍵字輸入加短延遲防抖**：避免每敲一個字就觸發重新計算
- **只顯示招募中且有名額的群組**：額滿或非招募中的群組不會出現，維持列表的可信度

## 驗證重點
- 探索頁本身是唯讀頁面，沒有任何寫入操作
- 關鍵字比對只是簡單的字串包含判斷，不是模糊搜尋
