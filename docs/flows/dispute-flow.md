# 申訴流程

## 使用者目標
成員在確認期內如果發現服務沒有正常啟用、或有其他問題，可以正式回報，凍結代管款項讓團主跟成員雙方有機會先自行溝通解決；真的無法達成共識、需要第三方仲裁時，才由平台裁定金流歸屬，避免僅憑團主單方陳述作為依據。

## 流程
1. 成員在確認期內點擊「回報問題」，複選問題原因、填寫說明，並**必須**附上截圖佐證
2. 送出後群組進入申訴中狀態，代管金額暫時凍結不動，團主與成員收到通知
3. 團主與成員可以在專屬的留言區直接溝通，確認問題解決後，團主可以標記「處理完成」，讓群組回到確認期、成員重新獲得一段確認窗口——不需要每次小問題都送交平台仲裁
4. 若雙方無法達成共識，管理員在後台可以看到完整的申訴內容、佐證附件與雙方對話記錄，據此裁定退款比例，不再只是憑群組編號盲選：
   - 全額退款給成員：成員離開群組並拿回款項，其餘成員不受影響
   - 全額撥款給團主：代管金額撥給團主，全員服務恢復正常
   - 部分退款：雙方各拿回一部分金額，成員留在群組內
5. 裁定結果會通知雙方，並留下一筆結構化的裁定紀錄，供管理員後續查詢歷史案件

## 產品決策
- **申訴必須附上佐證截圖**：避免缺乏依據的申訴，讓裁定有明確憑證
- **裁定逾期不會自動判定**：任何一方獲勝都可能對另一方不公平，寧可讓管理員手動處理，也不自動代為決定，只是把逾期案件優先排到管理員的處理清單最前面
- **裁定影響範圍精準限定在申訴的那位成員身上**：其餘成員的代管與訂閱完全不受牽連
- **裁定不再是二選一**：早期版本只能整筆判給某一方，實際案例常常是雙方都有一部分責任，因此改成管理員可自訂退款金額的彈性裁定，並保留每一筆申訴從提出到結案的完整歷史

## 驗證重點
- 送出申訴要求群組正處於確認期、且請求人確實是該群組成員
- 裁定只有平台管理員能操作
